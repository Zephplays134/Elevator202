# Project 2026 Status Monitor

A lightweight, mobile-friendly public-information dashboard for tracking public announcements about Tableboard Studios' Project 2026.

## View it
- Open [index.html](./index.html) in a browser.
- If GitHub Pages is enabled for this repository, the page can be published from the repository's `main` branch.

## Current public-evidence summary
- **Project listed publicly:** Yes. A public Tableboard Studios group listing includes Project 2026 and says details are to be announced.
- **Internal testing confirmed publicly:** Not confirmed. This dashboard cannot determine whether private internal testing is occurring.
- **Release date and detailed features:** Not announced in the public sources referenced by this dashboard.

“Not publicly confirmed” is not proof that something is not happening privately. Update the dashboard only when a reliable public source supports a change.

## Scope
This is a static status dashboard. It does not access private servers, developer-only builds, or internal testing systems, and it does not claim to automatically verify private activity.
