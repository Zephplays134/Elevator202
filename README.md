# Project 2026 Status Monitor

A mobile-friendly public-information dashboard for tracking official public announcements about Tableboard Studios' Project 2026 and Cruise Ship Simulator.

## Current status — reviewed October 17, 2026

| Question | Status | What this means |
|---|---|---|
| Is Project 2026 currently confirmed on the official projects page? | **Not currently visible** | Earlier developer statements you shared described plans to work on it, but the currently accessible official projects page does not list Project 2026. |
| Has internal testing started? | **Not publicly confirmed** | I cannot verify private internal testing from public sources. Do not mark this as a confirmed “Yes” without an explicit official developer statement. |
| Is a release date confirmed? | **No public date verified** | Treat dates and launch windows as unannounced until Tableboard Studios confirms them. |
| Are elevator types and ship systems confirmed? | **Not verified** | Elevators, PA systems, and other mechanics should be labeled planned or confirmed only when an official source says so. |

**Important:** “Not publicly confirmed” is not proof that internal testing is not happening. It means the available public evidence does not establish a yes or no.

## What qualifies as testing confirmation?

Use a dated official announcement, developer post, or official test-access notice that explicitly identifies Project 2026 and says testing has started. A testing server name, an unrelated elevator repository, speculation, or the existence of a project listing alone is not sufficient evidence.

## Scope and limitations

This repository tracks public information. It does not access private Roblox servers, developer-only builds, private Discord channels, or internal testing systems. It cannot truthfully claim to automatically detect private activity. Public-source checking and page refreshes also do not guarantee that every announcement is captured immediately.
