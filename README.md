# Project 2026 Status Monitor

A mobile-friendly public-information dashboard for tracking public announcements about Tableboard Studios' Project 2026 and Cruise Ship Simulator.

| Question | Status | Evidence |
|---|---|---|

| Has internal testing started? | **Not publicly confirmed** | The search did not find a reliable official statement explicitly confirming that internal testing has started. |
| Is a release date confirmed? | **No public date verified** | The secondary listing says “To be announced”; no verified launch date was found. |
| Are elevator types and ship systems confirmed? | **Not verified** | Elevators, PA systems, and other mechanics should remain unconfirmed until supported by a developer source. |

**Important:** A project listing is not proof of active internal testing. “Not publicly confirmed” also does not prove that testing is not happening privately. The dashboard must not label testing “YES” unless a reliable official source explicitly confirms it.

## What qualifies as testing confirmation?

Use a dated official Tableboard Studios announcement, developer post, or official test-access notice that explicitly identifies Project 2026 and says testing has started. A third-party project listing, a test-server name by itself, or speculation is not enough.

## Scope and limitations

This repository tracks public information. It does not access private Roblox servers, developer-only builds, private Discord channels, or internal testing systems. The dashboard links to a Google search for manual rechecking; it does not automatically run Google searches in the background or guarantee instant detection of announcements.
